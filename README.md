# loom-python

Python implementation of the language-neutral Loom protocol.

The Loom contract and normative semantics live in FlossWare/loom. This repository realizes those semantics in Python. It is not the definition of Loom.

Repository family:

    loom
    loom-python
    loom-ai
    loom-ai-python

Future language implementations such as loom-java and loom-erlang are peers.

See FlossWare/standards ADR-0024 for the contract-centric repository naming and layering convention.
